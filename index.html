About Hindu Companion

Hindu Companion is a privacy-focused local-first web application designed to support daily Japa practice and devotional routine. It allows spiritual practitioners to track Naam Japa automatically or manually without requiring account registration or internet connectivity.

Lock-Screen Resilience & Accuracy

When phone screens lock or browsers throttle background timers, standard JavaScript intervals stop. Hindu Companion measures elapsed real time between practice timestamps, calculating accurate completed counts and 108-bead mala rounds upon returning.

Local-First Architecture

All data is saved directly in your device’s browser storage (`localStorage`). No servers, analytics, or external requests are involved. You can export or import your data anytime as a JSON file.
